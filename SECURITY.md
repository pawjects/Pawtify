# Security Policy for Pawtify

## Supported Versions

Only the latest `main` branch deployment is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Privacy & Security Core Principles

Pawtify is designed as a browser-based, privacy-first static application. We ensure that:
1. **No External Tracking**: No user listening habits or playlist data are transmitted to any external servers.
2. **Local Storage**: Storage is strictly used for client-side preferences (e.g., volume states, theme overrides, local playlists).
3. **Third-Party Scripts**: No third-party tracking or analytics scripts are embedded in the player.

## Reporting a Vulnerability

We take the security and privacy of Pawtify very seriously. 

If you discover a vulnerability or a privacy leak within the audio routing, please open a private security advisory on GitHub or contact the maintainers directly. 

**Please do not submit a public issue for zero-day vulnerabilities.** 

We will review the report and strive to patch any confirmed vulnerabilities within 48 hours.

## Policy Changes

This policy is subject to change. Any significant changes will be communicated via the repository's changelog.
